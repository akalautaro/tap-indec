# Seguridad

## Versiones soportadas

La última release menor recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No abras un issue público. Escribí a cellilautaro@gmail.com con:

- descripción del problema,
- pasos para reproducirlo,
- impacto que estimás,
- versión afectada.

Respondo dentro de los cinco días hábiles. Si el reporte es válido, coordino
la fecha de divulgación con vos antes de publicar el fix.
