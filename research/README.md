# Investigación de la API

`catalog.md` y `catalog.json` documentan la investigación que se usó para armar
`tap_indec/catalog.json`. Incluyen las series descartadas, la cobertura de la
EPH y las trampas de la API.

No forman parte del paquete que se publica en PyPI. El catálogo que usa el tap
es `tap_indec/catalog.json`.
